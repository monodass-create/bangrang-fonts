# 0.4 검수 기록 — 2026-11-04

제작자 판단: 이번에 확인한 브라우저 본문·목록과 게임 UI에서는 사용할 수 있다. UI체 14px 짧은 안내, 16px 본문·목록, 18px 긴 설명, 기록체 24px 이상 제목을 시작점으로 권한다. 이 수치는 대표 화면 검수에 따른 판단이며 보편적인 최소 크기나 사람 대상 오독률을 측정한 결과가 아니다.

## 실제 수정과 파일 검사

작은 글자에서 U+AE80/U+AEB8의 회색조 결과가 같아지는 결함을 발견했다. 두 갈래 모음의 폭·갈래 간격을 수정한 뒤 아래 모든 검사 크기에서 해당 중복과 다른 완전 중복이 없어졌다. 획의 겹침·사각 자모 구멍·받침 및 영문 곡선을 함께 보완했다.

[구조 검사](0.4-regression-validation.json): 두 서체의 완성형 한글 11,172자 매핑·비어 있지 않음·서로 다른 윤곽, 범위·메트릭·버전·체크섬 통과. UI체는 11,172자의 설계상 떨어진 성분 수와 외곽 윤곽 수를 비교하여 불일치 0. 기록체에는 이 UI 전용 성분 수 검사를 적용하지 않았다.

[재생성 검사](../reviews/0.4-source-rebuild-check.json): 이전 TTF 없이 원본 좌표만으로 두 파일을 재생성. 빌드 시각과 관련 체크섬을 제외한 테이블 동일. 기록체의 윤곽·가로 메트릭·문자 매핑·커닝은 0.3과 동일.

UI체의 합집합 처리는 [fontTools removeOverlaps](https://github.com/fonttools/fonttools/blob/main/Lib/fontTools/ttLib/removeOverlaps.py)와 skia-pathops 0.9.2를 사용했다. gasp 값 10은 회색조·대칭 스무딩 요청이며 TrueType 힌팅 프로그램을 만든 것은 아니다. [Microsoft gasp 설명](https://learn.microsoft.com/en-us/typography/opentype/otspec180/gasp)

## 작은 크기 검사

Pillow 12.3.0 / FreeType 2.14.3, 같은 정수 기준점. UI 11·12·13·14·15·16·18·24px, 기록체 18·24·32px. 11개 조건 × 11,172자 = 122,892개 래스터. 빈 래스터 0, 완전히 같은 회색조 묶음 0. [원시 결과](0.4-small-size-validation.json)

| UI 크기 | 128 임계값 유사 후보 묶음 |
|---:|---:|
| 11 | 482 |
| 12 | 591 |
| 13 | 621 |
| 14 | 31 |
| 15 | 185 |
| 16 | 4 |
| 18 | 0 |
| 24 | 0 |

기록체 세 크기는 0이다. 임계값 비교는 안티앨리어싱의 명도 차이를 버린다. 후보 수는 불량·오독·동일 표시 개수가 아니며, 0도 가독성 보장이 아니다. 크기별 결과는 단조롭지 않고 이전 판보다 모든 크기에서 수치가 좋아졌다고 주장하지 않는다. 11~13px 복잡한 한글 본문은 계속 비권장이다.

## 실제 표시

- [Windows 결과](../reviews/0.4-windows-private-font-check.json): 프로세스 내부에 임시 등록 후 실제 0.4 선택, 두 서체 각각 11,172자 조회, 해제 확인. 영구 설치·재시작 검사는 아니다.
- [브라우저 결과](../reviews/0.4-browser-validation.json): Opera, devicePixelRatio 1. 두 TTF 로드, 14/16/18px 문장·목록, 숫자 12px, 기록체 28px 제목, 대표 NFC/NFD 픽셀 동일 확인. 목재/Wood 입력 각각 1행, 지우기 4행 복귀 확인. [화면](../specimens/브라우저-0.4-하단.png)
- [PDF 결과](../reviews/0.4-pdf-embedding-check.json): [2쪽 견본](../specimens/문서견본-0.4.pdf)에 두 TTF 내장, 한영 추출, Poppler 렌더링 후 2쪽 모두 육안 확인. 줄 잘림·겹침·빈 상자 미발견. 출력물 인쇄나 Word 저장 검사는 아니다.

## 미검수

전체 음절의 개별 육안 검수, 사람 대상 장시간 읽기, 실제 Windows 125/150/200% 배율 설정, 영구 설치와 재시작, Word·다른 운영체제, 지원 범위 밖 문자와 여러 굵기는 미검수 또는 미지원이다. 보이는 결과를 점검한 범위와 자동 검사 통과 범위를 구분한다.

이전 결과는 [v0.3.0 보존본](https://github.com/monodass-create/bangrang-fonts/tree/v0.3.0)에 남아 있다.
